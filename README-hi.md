# dsh-mcp-market

**DeepSeek Harness के भीतर ModelScope MCP मार्केटप्लेस ब्राउज़, स्कैन और सिंक करें — और MCP
सर्वर को एक क्लिक में इंस्टॉल, सक्षम, अक्षम या हटाएँ।**

[English](README.md) · [简体中文](README-zh.md) · [Español](README-es.md) · [Português](README-pt.md) · [हिन्दी](README-hi.md)

यह DSH Web साइडबार में **MCP मार्केट** पैनल जोड़ता है। यह
[modelscope.cn/mcp](https://modelscope.cn/mcp) (12,000+ सेवाएँ) से कैटलॉग लाता है, हर रिकॉर्ड को
DSH-संगत MCP कॉन्फ़िगरेशन में बदलता है, और उसे आपकी प्रोफ़ाइल की `cordis.patch.yml` में लिखता है —
जहाँ DSH उसे HMR से हॉट-रीलोड करता है।

## Features

- **मार्केट टैब** — खोजें, क्रमबद्ध करें (प्रासंगिकता / स्टार / लोकप्रियता / हाल में अपडेट),
  श्रेणी और होस्टेड-या-लोकल से फ़िल्टर करें, और इंस्टॉल करें। श्रेणी नाम ModelScope के चीनी लेबल हैं
  (API केवल अंग्रेज़ी slug देती है; सभी 100 श्रेणियाँ शामिल हैं) — मूल slug देखने के लिए चिप पर हॉवर
  करें। क्रमबद्धता और फ़िल्टर DSH के मूल ड्रॉपडाउन मेन्यू का उपयोग करते हैं, जिससे वे बगल के बटनों
  से मेल खाते हैं।
- **इंस्टॉल किए गए टैब** — हर MCP सर्वर और उसकी लाइव स्थिति (चालू / विफल / लोड हो रहा है /
  अक्षम), पंजीकृत टूल की संख्या, और क्रियाएँ: सक्षम करें, अक्षम करें, कनेक्शन जाँचें, हटाएँ।
- **कैटलॉग सिंक** — स्थानीय इंडेक्स बनाता है ताकि खोज, क्रमबद्धता और फ़िल्टर हर अक्षर पर नेटवर्क न
  छुएँ। ModelScope अनाम क्वेरी को 300 पंक्तियों तक सीमित करता है, इसलिए सिंक कीवर्ड-फ़ैनआउट
  (~160 अनुरोध) से चलता है और 12,500 सेवाओं के कैटलॉग का ~67% कवर करता है; पैनल असली कवरेज बताता
  है, इंडेक्स को पूरा होने का दिखावा नहीं करता। इंक्रीमेंटल अंतर बताता है कि क्या जोड़ा, अपडेट या
  हटाया गया। बाकी कमी खोज पूरी करती है: क्वेरी लिखते ही मार्केटप्लेस से लाइव भी पूछा जाता है।
- **निर्धारित सिंक** — मैनुअल बटन के अलावा इंडेक्स नियमित अंतराल पर स्वतः दोबारा आता है, और
  शुरुआत में भी जब कैश मौजूद न हो या पुराना हो। सब कुछ कॉन्फ़िगर करने योग्य है और पैनल पिछले
  तथा अगले सिंक का समय दिखाता है।
- **ModelScope खाते की आवश्यकता नहीं** — सार्वजनिक API में लॉगिन नहीं चाहिए, और इंडेक्स की लगभग
  76% सेवाओं में ऐसा कॉन्फ़िगरेशन होता है जिसे DSH सीधे उपयोग कर सकता है (8,377 रिकॉर्ड पर मापा
  गया; नीचे देखें)।
- **अन्य प्लगइन के साथ संगत** — यह केवल `cordis.patch.yml` में अपने चिह्नित ब्लॉक को फिर से लिखता
  है; अन्य प्लगइन की पंक्तियाँ बाइट-दर-बाइट सुरक्षित रहती हैं।

## Install

```bash
dsh plugin --profile web add dsh-mcp-market
```

वेब प्रोफ़ाइल को एक बार पुनः आरंभ करें, फिर बाएँ साइडबार में **MCP मार्केट** खोलें।

## How it works

एक MCP सर्वर `~/.dsh/profiles/<profile>/cordis.patch.yml` में एक पंक्ति है:

```yaml
- id: mcp-market-<serverName>
  name: "@deepseek-ai/dsh-mcp-client"
  # disabled: true          # ← «अक्षम करें» बिल्कुल यही फ़ील्ड है
  config:
    serverName: <serverName>
    transport: stdio | streamable-http
```

इंस्टॉल करना एक पंक्ति जोड़ता है, हटाना एक पंक्ति घटाता है, और अक्षम करना `disabled: true` सेट
करता है। बदलाव HMR से लागू होते हैं।

ModelScope की **होस्टेड** तैनाती के लिए खाता चाहिए और वह SSE पता लौटाती है जिसे DSH समर्थित नहीं
करता; यह प्लगइन जानबूझकर उनका समर्थन नहीं करता।

### कॉन्फ़िगरेशन मैपिंग

| ModelScope फ़ील्ड | DSH कॉन्फ़िग |
|---|---|
| `StreamableHTTPServerConfig` | `transport: streamable-http` + `url` (+ `headers`) |
| `ServerConfig` | `transport: stdio` + `command` / `args` / `env` |
| `SSEServerConfig` | *समर्थित नहीं* — DSH में SSE ट्रांसपोर्ट नहीं है; पैनल इन्हें «समर्थित नहीं» दिखाता है |
| `EnvSchema` | इंस्टॉल के समय फ़ॉर्म; `<required>` जैसी प्लेसहोल्डर वैल्यू कभी नहीं लिखी जातीं |

प्राथमिकता रिमोट → लोकल है। इंडेक्स के 8,377 रिकॉर्ड पर मापा गया:

| मिली कॉन्फ़िग | हिस्सा |
|---|---|
| `ServerConfig` (लोकल, stdio) | 67.5% |
| `StreamableHTTPServerConfig` (सीधा पता) | 8.4% |
| केवल `SSEServerConfig` → **इंस्टॉल नहीं हो सकता** | 24.1% |

**इंडेक्स की 75.9% सेवाएँ इंस्टॉल हो सकती हैं**; इनमें 23.4% को कम से कम एक एनवायरनमेंट वेरिएबल चाहिए।

### इंडेक्स ~67% पर क्यों रुकता है, और सिंक असल में क्या करता है

सार्वजनिक API अनाम अनुरोधों पर **300 का ऑफ़सेट कैप** लगाती है: जैसे ही
`(PageNumber − 1) × PageSize` 300 तक पहुँचता है, आगे का हर पृष्ठ खाली लौटता है *और* `TotalCount`
शून्य हो जाता है। 11 अलग-अलग पृष्ठ-चौड़ाई/पृष्ठ-संख्या संयोजनों पर मापा गया — कटाव हमेशा ठीक 300
पर होता है, यानी यह सर्वर-साइड कोटा है, पेजिंग की गलती नहीं। इसलिए «जब तक खत्म न हो पेज करते जाओ»
वाला सिंक 12,520 में से केवल 300 सेवाएँ (2.4%) लाता है।

जो काम करता है वह `Query` है — यह असली कीवर्ड खोज है (`finance` → 20 परिणाम, `搜索` → 222)।
इसलिए सिंक कीवर्ड सूची पर फ़ैनआउट करता है (26 अक्षर, 10 अंक, ~50 सामान्य शब्द, और कैटलॉग की
श्रेणी-नाम) और परिणामों को id से जोड़कर डुप्लीकेट हटाता है:

| कीवर्ड | इंडेक्स | कवरेज | अनुरोध |
|---|---|---|---|
| 36 (अक्षर + अंक) | 7,132 | 57.0% | 100 |
| 80 | 8,331 | 66.6% | ~155 |
| 160 | 8,403 | 67.1% | 236 |

लाभ जल्दी चपटा हो जाता है — अंतिम 80 शब्दों ने केवल 72 रिकॉर्ड जोड़े — इसलिए डिफ़ॉल्ट सूची 96 पर
रुकती है। एक सिंक में लगभग 4 मिनट और ~160 अनुरोध लगते हैं।

बाकी अंतर खोज के समय भरा जाता है: क्वेरी लिखते ही पैनल मार्केटप्लेस से लाइव भी पूछता है और दोनों
परिणाम-समूह मिला देता है।

## Scheduled sync

दो ट्रिगर एक ही लॉक साझा करते हैं — मैनुअल और निर्धारित सिंक कभी एक साथ नहीं चलते।

| ट्रिगर | कब | डिफ़ॉल्ट |
|---|---|---|
| **मैनुअल** | पैनल में **कैटलॉग सिंक** दबाने पर | हमेशा उपलब्ध |
| **शुरुआत** | हर बार शुरू होने पर एक बार, केवल यदि कैश न हो या 6 घंटे से पुराना हो | चालू, शुरू होने के 15 सेकंड बाद |
| **अंतराल** | DSH चलने के दौरान हर `intervalHours` | हर 24 घंटे |

अपनी प्रोफ़ाइल की `cordis.patch.yml` में **वही `id`** वाली पंक्ति जोड़ें — प्रोफ़ाइल परत जीतती है,
और patch पूरा `config` बदल देता है, इसलिए जिन कुंजियों को रखना है उन्हें दोबारा लिखें:

```yaml
- id: mcp-market
  name: dsh-mcp-market
  config:
    autoSync: false        # अंतराल पूरी तरह बंद करें
    intervalHours: 12      # 0.25 – 168
    syncOnStart: true
    startDelayMs: 30000
    maxRequests: 400       # कीवर्ड फ़ैनआउट का अनुरोध बजट
```

कॉन्फ़िग बदलाव HMR से हॉट-रीलोड होते हैं। पैनल की स्थिति पंक्ति वर्तमान शेड्यूल और पिछला सिंक
समय दिखाती रहती है। टाइमर प्लगइन के जीवनकाल से बंधे हैं और अनलोड पर हट जाते हैं।

## Development

```bash
node test/patch.test.mjs         # कॉन्फ़िग फ़ाइल सुरक्षा
node test/market.test.mjs        # फ़िल्टरिंग, रूपांतरण, तुलना + लाइव कैटलॉग
node test/scheduler.test.mjs     # सिंक शेड्यूल: कॉन्फ़िग सीमाएँ, जीवनचक्र, समवर्ती चलन
node test/keywords.test.mjs      # कीवर्ड फ़ैनआउट + 300 का अनाम कैप
node test/status.test.mjs        # लोडर प्रविष्टि, fiber चरण, पंजीकृत टूल गिनती
node test/client-render.test.mjs # बिना ब्राउज़र क्लाइंट बंडल रेंडर करता है + स्रोत गार्ड
node test/wire-contract.test.mjs # manifest ↔ क्लाइंट योगदान समानता + आरक्षित नाम
```

`market.test.mjs` और `keywords.test.mjs` को नेटवर्क चाहिए; केवल ऑफ़लाइन भाग चलाने के लिए
`SKIP_ONLINE=1` सेट करें।

## Uninstall

```bash
dsh plugin --profile web remove dsh-mcp-market
```

आपके इंस्टॉल किए गए सर्वर `cordis.patch.yml` में बने रहते हैं (वे सामान्य DSH MCP पंक्तियाँ हैं)।
फ़ाइल साफ़ रखनी हो तो उन्हें इंस्टॉल किए गए टैब से हटाएँ।
